About

IN AUTHORITY

A simple daily practice of praying for people serving in public office.

Data & Privacy

The current congressional roster is requested from a public congressional data repository and cached locally for reliability. Your prayer history and optional ZIP code stay in this browser's local storage. There is no account or server-side prayer-history database in this release candidate.

Sources

Congressional roster: unitedstates/congress-legislators.
Official House delegation lookup: house.gov.

Release note

This build is designed to be deployable as a static HTTPS site. For a larger launch, add a small backend cache/proxy, centralized analytics/monitoring, and a production privacy/legal review.
